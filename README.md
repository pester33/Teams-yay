# Gaming Teams (Geode mod)

Team levels for the Gaming team: build together live, progress saved online.

## Download
- **GD 2.2091** (Geode 6.0.0): https://github.com/pester33/Teams-yay/releases/download/latest-build-2.2091/pester.gaming-teams.geode
- **GD 2.2081** (Geode 5.11.2): https://github.com/pester33/Teams-yay/releases/download/latest-build/pester.gaming-teams.geode

## Setup (once)
Run `sql/setup.sql` in the Supabase SQL Editor (same project as GD Gaming Collab).

## Who's on the team
Edit `data/members.txt`: one GD username per line. A line with `*` lets everyone in. Changes work right away, no mod update needed.
